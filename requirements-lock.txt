# requirements.txt declara minimos y sirve para trabajar; este archivo sirve para REPETIR.
# Si una version nueva de scikit-image o de opencv cambia una metrica, con este archivo el
# resultado sigue siendo el mismo:
#
#     pip install --no-deps -r requirements-lock.txt --extra-index-url https://download.pytorch.org/whl/cu121
#
# LOS DOS DETALLES DEL COMANDO NO SON OPCIONALES: sin ellos la instalacion falla de dos formas
# distintas, ninguna evidente.
#
# 1) --extra-index-url. torch 2.5.1+cu121 y torchvision 0.20.1+cu121 son las ruedas con CUDA y NO
#    estan publicadas en PyPI. Sin el indice de PyTorch, pip corta con «Could not find a version
#    that satisfies the requirement torch==2.5.1+cu121». Va tambien como directiva abajo, de modo
#    que el archivo funciona aunque el comando se copie sin ella.
#
# 2) --no-deps. Este archivo es el cierre COMPLETO de dependencias, ya fijado: no hay nada que
#    resolver, y resolver de nuevo hace fallar la instalacion. Motivo concreto: dtcwt 0.14.0 declara
#    numpy<2.0.0 y opencv-python 4.13.0.92 declara numpy>=2. Ninguna version de numpy satisface las
#    dos, asi que el resolvedor de pip rechaza el conjunto entero con ResolutionImpossible.
#
#    Y sin embargo el entorno publicado tiene numpy 1.26.4 con opencv 4.13.0.92 y funciona: la rueda
#    de cv2 esta compilada contra la ABI de numpy 2, que es compatible hacia atras en tiempo de
#    ejecucion. El entorno llego a ese estado instalando opencv despues de numpy, sin volver a
#    resolver, y es el estado en el que se calcularon las tablas. --no-deps instala exactamente esas
#    versiones y reproduce esa combinacion; dejar que pip resuelva daria otro opencv, y opencv es
#    justamente la biblioteca que implementa la morfologia de la que sale todo el resultado.
#
#    Instalar sin --no-deps NO es una alternativa mas floja: es un error, y pip lo dice.
#
# Si lo unico que se quiere es la evaluacion de calidad en CPU, requirements.txt alcanza y se
# instala normal. Este archivo solo agrega la parte de deteccion, que necesita GPU.
#
# EL INDICE DE PYTORCH TAMBIEN VA DECLARADO ABAJO, para que el archivo funcione solo.
